How it works

  • Features (from past data only), for each sector each month-end: returns over 1, 3, 6 and 12 months (skipping the latest month), volatility, and distance from the 200-day average, each ranked against the other sectors; plus market trend, market volatility and the T-bill rate.
  • Target: how the sector ranks against the others next month.
  • Walk-forward training: at each month-end the model trains on every earlier month (at least 36), then predicts. It never sees a month before deciding on it.
  • Portfolios: ML moderate holds the top 3 sectors, always invested. ML safe holds the same 3 but moves to T-bills when SPY ends the month below its 200-day average.
  • Holdout: 2018–today stays locked until the design is final, then gets tested once. Caveat: the baseline report already showed how simple momentum did after 2018, so the holdout isn't perfectly blind.
  • Same engine as the baselines: next-day fills, drift between rebalances, 5 bps costs, cash earns T-bills. Past results are not a forecast.
